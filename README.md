# MRFPS — הצורך והמחדלים

אתר HTML סטטי בעברית, RTL, שבעה דפים מקושרים.

## פתיחה
חלצו את ה-ZIP, פתחו index.html בדפדפן. אין צורך בשרת או בספריות חיצוניות.

## Google Sites
אפשר להטמיע כל דף באמצעות URL ציבורי לאחר פרסום האתר באחסון סטטי (למשל GitHub Pages). Google Sites > Insert > Embed > By URL.
הדבקת קוד HTML יחיד ב-Embed Code לא תעביר אוטומטית קבצי CSS/JS ואת שאר הדפים; לכן מומלץ לפרסם את כל התיקייה באתר סטטי ולקשר אליו מתוך Google Sites.

## סטטוס מקורות
המסמך משלב חומרים שנקראו מתוך מסמכי המיזם ב-Google Drive ומקורות היסטוריים ומחקריים ידועים. מראי מקום מדויקים ברמת עמוד, בעיקר למירון ולתחקירי 7 באוקטובר, דורשים בדיקת המשך לפני פרסום כהוכחות פרטניות.
